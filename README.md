# Hey, I'm Swompen

I am a full-stack developer from Sweden. I build a Godot MMORPG, an AI agent
system for my homelab, and tools for the FiveM community.

## Current work

- **A Godot MMORPG** — a multiplayer game project with 500+ commits. It
  uses generated world content (maps, dungeons, biomes) and a review
  pipeline for art and design.
- **A private AI agent platform** — an orchestration system for AI coding
  agents (Claude Code and Codex). It runs a growing set of skills and
  subagents across my workstation and a small homelab.
- **Homelab** — a Proxmox host, a Docker VM, and a Synology NAS for
  self-hosted services. My workstation runs Arch Linux with Hyprland
  (Omarchy).

Most of this work lives in private repositories, so the public list below
does not show the full picture.

## Background

I built server tools for the FiveM community for several years. My public
repos include a media host, a streaming asset optimizer, and several
gameplay scripts in Lua.
